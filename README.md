# Free LLM Pool Guide · 免费大模型聚合池搭建指南

> 一个**纯教学**项目：手把手教你把分散在各平台的免费大模型额度，
> 聚合成一个「OpenAI 兼容」的统一入口，并用限流网关管住调用频率。
> 让任何支持自定义 OpenAI 接口的客户端，都能一处填写、白嫖多家。

> ⚠️ **免责声明**：本项目仅供学习与研究。请遵守你所用每个平台的服务条款（ToS）。
> 免费额度由各平台提供，请勿滥用或用于商业倒卖。所有配置中的密钥均为占位符，
> **仓库中不含、也不应包含任何真实密钥**。

## 🧩 这套架构解决什么痛点

白嫖党常见的三大烦恼：

1. **入口散**：A 平台一个地址、B 平台一个地址，客户端要来回改。
2. **额度碎**：每家送一点，单个不够用，想自动轮着薅。
3. **限流烦**：有的平台有每分钟频率限制（RPM），超了就被临时封。

本方案的解法：

- 用 **API 聚合网关**把多家免费源**聚成一个池子**，对外只暴露一个地址。
- 用 **限流代理网关**在池子前面**管住频率**，避免触发平台 RPM 封禁。
- 客户端只需填**一个** OpenAI 兼容地址 + 一个本地 key，即可调用整个池子。

## 🏗️ 架构总览

```
┌─────────────────────────────────────────────────────────┐
│                      你的客户端                          │
│   (任意支持「自定义 OpenAI 接口」的工具)                  │
│   填写:  Base URL = http://localhost:4000/v1             │
│          API Key = sk-local-anything                     │
└───────────────────────────┬─────────────────────────────┘
                            │  OpenAI 兼容请求
                            ▼
┌─────────────────────────────────────────────────────────┐
│              限流代理网关 (LiteLLM Proxy)                 │
│   • 统一入口 :4000                                       │
│   • 按「模型组」自动轮询 / 故障转移                       │
│   • 每个上游模型设 rpm / tpm 限速，防止触发平台封禁        │
└───────────────────────────┬─────────────────────────────┘
                            │  按策略分发
              ┌─────────────┼─────────────┬──────────────┐
              ▼             ▼             ▼              ▼
        ┌──────────┐ ┌──────────┐ ┌──────────┐  ┌──────────┐
        │ 免费源 A  │ │ 免费源 B  │ │ 免费源 C  │  │ 免费源 ...│
        │(聚合池)  │ │(官方免费) │ │(开发者额度)│  │          │
        └──────────┘ └──────────┘ └──────────┘  └──────────┘
```

**角色分工**：

| 角色 | 作用 | 本指南对应 |
|---|---|---|
| **聚合网关** | 把多家免费源聚成一个池子，对外一个地址，支持轮询/故障转移 | `newapi` 类自建聚合面板 |
| **限流代理** | 站在池子前面，按模型设 rpm/tpm，统一限速、统一记账 | `litellm` proxy |
| **客户端** | 你日常用的工具，填一个地址即可 | 任意 OpenAI 兼容客户端 |

> 💡 为什么叠两层（聚合 + 限流）而不是用一层？
> 聚合层负责「多源合并」，限流层负责「频率管控 + 统一计费观测」。
> 分开后，限流策略可以精细到「每个上游模型每分钟几次」，这是单纯聚合面板做不到的。

## 🚀 快速开始

详细步骤见 [`docs/教程-小白版.md`](docs/教程-小白版.md)。这里给概览：

1. **部署聚合网关**，在它的管理界面里把你的各免费源逐个添加为「渠道」。
2. **配置限流代理**，编辑 `config/litellm.config.example.yaml`，填入聚合网关的上游地址（**用占位符，别填真实 key**）。
3. **启动限流代理**，对外暴露一个本地端口。
4. **客户端填写**该本地地址 + 任意本地 key，开始使用。

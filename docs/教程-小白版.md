# 小白版教程 · 零基础搭起你的免费模型池

> 目标读者：没碰过服务器、没写过配置的小白。
> 跟着做，最后你会得到**一个本地地址**，填进任意客户端就能白嫖多家免费模型。
>
> ⚠️ 全程涉及密钥的地方，本教程一律用 `YOUR_XXX_HERE` 表示，**请换成你自己的，但别截图发网上、别提交进 Git**。

---

## 第 0 步 · 先搞懂三个词

| 词 | 人话解释 |
|---|---|
| **聚合网关** | 一个网页面板，你把各家的免费模型地址都填进去，它帮你合成一个统一入口 |
| **限流代理** | 站在聚合网关前面的一道闸，帮你控制"每分钟调几次"，防止被平台封 |
| **OpenAI 兼容** | 一种通用的接口格式。支持它的客户端，只要换地址就能换模型 |

**数据流向**：客户端 → 限流代理 → 聚合网关 → 各家免费源

---

## 第 1 步 · 准备工作

你需要：

- 一台能联网的电脑（Windows / Mac / Linux 都行）
- 装好 **Docker**（聚合网关一般用 Docker 跑最省事）
- 装好 **Python**（限流代理是 Python 工具）
- 各平台的**免费账号**，并在它们后台拿到各自的接口地址和密钥

> 💡 怎么拿免费源？
> 很多平台有免费额度：有的送开发者计划额度、有的有免费档、有的开源社区发免费 Key。
> 自己去各家官网注册、在控制台里创建 Key 即可。**每个 Key 都当宝贝，别外传。**

---

## 第 2 步 · 部署聚合网关

1. 用 Docker 把聚合网关跑起来（具体镜像名以你选的面板官方文档为准）。
2. 打开它的管理网页（一般是 `http://localhost:某端口`）。
3. 登录后台，找到「渠道 / 渠道管理」，**把你的每个免费源加进去**：
   - 选类型（一般选 `OpenAI` 兼容）
   - 填该源的**接口地址**（Base URL）
   - 填该源的**密钥**（Key）
   - 起个模型名
4. 全加完后，测试一下每个渠道是否「可用」。

> 到这一步，你已经有一个聚合入口了。但它还不会限流，下面加一道闸。

---

## 第 3 步 · 配置限流代理

1. 把本仓库的 [`config/litellm.config.example.yaml`](../config/litellm.config.example.yaml) 复制一份，改名 `litellm.config.yaml`。
2. 打开它，把里面所有 `YOUR_XXX_HERE` 换成**你聚合网关的地址和密钥**。
3. 按需调整每个模型的 `rpm`（每分钟请求数）——**这就是防封的关键**，别设太高。
4. 保存。**确认这个文件不会被提交进 Git**（本仓库已用 `.gitignore` 帮你挡了）。

---

## 第 4 步 · 启动限流代理

在配置文件所在目录打开命令行，运行：

```bash
pip install litellm[proxy]
litellm --config litellm.config.yaml
```

看到它监听在 `127.0.0.1:4000` 就成功了。

---

## 第 5 步 · 客户端填写

在你的客户端里（任何支持自定义 OpenAI 接口的工具）：

- **接口地址（Base URL）**：`http://127.0.0.1:4000/v1`
- **API Key**：填你在配置里 `master_key` 设的那个本地密钥
- **模型名**：填你在配置里起的 `model_name`（比如 `free-pool-chat`）

搞定！现在你调一次，请求会自动经过「限流 → 聚合 → 各家免费源」，
一个挂了还能自动切下一个。

---

## 第 6 步 · 验证

命令行跑一句测试（把 `YOUR_LOCAL_KEY` 换成你的本地密钥）：

```bash
curl http://127.0.0.1:4000/v1/chat/completions \
  -H "Authorization: Bearer YOUR_LOCAL_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"free-pool-chat","messages":[{"role":"user","content":"你好"}]}'
```

能返回模型回复，就大功告成。🎉
